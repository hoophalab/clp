# API Server

The CLP API Server is a Rust-based HTTP server that exposes CLP functionality through REST APIs.

## API reference

All public API endpoints are defined according to the [OpenAPI][openapi] Specification. The
generated public specification can be found [here][static-api-reference].

[openapi]: https://swagger.io/specification/
[static-api-reference]: ../../docs/src/_static/generated/api-server-openapi.json
